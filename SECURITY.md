# Security

Retake handles screen recordings, which often show things people would rather keep private. If you find a way it could leak something, I want to know.

Please don't open a public issue for security problems. Report them privately instead: open the **Security** tab of this repository and choose **Report a vulnerability**. Include what you did, what happened, and what you expected.

Things I especially want to hear about:

- A private detail that survives the blur, or a kind of secret the scan misses.
- The local API answering anything other than this computer.
- API keys showing up somewhere they shouldn't, like a project file, a log or the window.
- Anything that sends footage off the computer.

I'll reply as soon as I can and credit you in the fix unless you'd rather I didn't.
